# Lost Sock Simulator 3000

This repo shows some of the resources used in the making of [Lost Sock Simulator 3000](https://store.steampowered.com/app/4597220/Lost_Sock_Simulator_3000/), an incremental idle clicker game made while we were learning how to use Big Numbers in Unity3D.

![Lost Sock Simulator 3000](images/capsule_920.png)

### BigNumber implementation in Unity3D

In [src/BigNumber.cs](src/BigNumber.cs) you can find our implementation for `BigNumber`s in Unity3D. This implementation allows us to go from `zero` to `1e30` socks in our game (although the implementation allows much bigger numbers).
